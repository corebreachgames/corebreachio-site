# Corebreach public site — approved design

Approved by the user on 2026-10-26, including the feature/corebreachio-site branch.

A cinematic static company site for GitHub Pages. Charcoal and ivory follow the supplied Corebreach mark; warm brass and restrained motion connect it to Runefall. Editorial typography, generous spacing, a full-bleed Forge illustration and an oversized Runefall feature make the first view distinctive. The studio owns the main identity and Runefall occupies a featured-game section, leaving the structure ready for future titles.

Sections: studio introduction, featured Runefall story and game facts, actual gameplay video, screenshot gallery, studio philosophy, press/contact, and footer. A dedicated press page provides factual copy, attribution, screenshots, artwork and a ZIP download. No accounts, forms, database, analytics, external embeds or backend. No invented store listing, release date, company size or awards.

Assets come from the supplied logo and the exile-survivors project. Gameplay captures are actual runtime media; concept artwork is described as artwork. Media is compressed locally. Video is user initiated and includes a poster. Reduced-motion preferences disable ambient animation. Gallery dialogs support keyboard navigation and focus restoration.

The site is buildless HTML, CSS and small progressive JavaScript, with relative URLs for project-path hosting, a CNAME for corebreach.io and a GitHub Pages Actions workflow.
